# CalTG - Telegram бот для подсчета калорий

Современный Telegram бот, который помогает пользователям отслеживать потребление калорий с использованием ИИ для распознавания пищи и интеграции с базой данных питания USDA.

## Основные функции

- 🤖 **Распознавание еды с помощью ИИ**: Загружайте фотографии своих блюд для автоматического определения продуктов и оценки питательной ценности
- 📝 **Текстовый ввод**: Описывайте свои блюда в текстовом виде для быстрого добавления
- 📊 **Ежедневное отслеживание**: Отслеживайте дневное потребление калорий в сравнении с вашими целями
- 👤 **Персонализированные профили**: Установите личные параметры (возраст, вес, рост) для расчета персональных целей по калориям
- 🔔 **Напоминания**: Настраивайте пользовательские временные интервалы для напоминаний о регистрации приемов пищи
- 📅 **История**: Просматривайте историю питания со временем
- 🌐 **Поддержка вебхуков**: Развертывание на облачных платформах, таких как Render, с интеграцией вебхуков

## Технологический стек

- **Python 3.11+**
- **python-telegram-bot v20+** (асинхронная версия)
- **FastAPI** для веб-сервера и обработки вебхуков
- **PostgreSQL** для постоянного хранения данных
- **SQLAlchemy 2.0** с asyncpg для ORM
- **Alembic** для миграций базы данных
- **OpenRouter API** для ИИ-распознавания еды
- **USDA FoodData Central API** для точных данных о питательных веществах

## Настройка

### Предварительные требования

- Python 3.11+
- База данных PostgreSQL
- Токен Telegram бота (получить у [@BotFather](https://t.me/BotFather))
- Ключ API OpenRouter (для обработки ИИ)
- Ключ API USDA (для получения данных о питании)

### Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd caltg
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```

4. Заполните свои ключи API и учетные данные базы данных в файле `.env`:
```env
# Telegram
TELEGRAM_BOT_TOKEN=your_token_here

# Database
DATABASE_URL=postgresql+asyncpg://user:pass@host:5432/db

# OpenRouter
OPENROUTER_API_KEY=your_key_here
OPENROUTER_MODEL=gpt-4.2-mini # или google/gemini-2.0-flash-001

# USDA
USDA_API_KEY=your_key_here
```

### Локальный запуск

Для локальной разработки с опросом:
```bash
python -m app.bot
```

Для локальной разработки с вебхуками (требуется ngrok или аналог):
```bash
uvicorn app.main:app --reload --port 8000
```

### Развертывание на Render

1. Подключите свой репозиторий GitHub к Render
2. Создайте новый веб-сервис
3. Установите команду сборки: `pip install -r requirements.txt`
4. Установите команду запуска: `gunicorn app.main:app -w 4 -k uvicorn.workers.UvicornWorker --bind 0.0.0.0:$PORT`
5. Добавьте свои переменные среды в панели управления Render

## Команды

- `/start` - Регистрация и начало использования бота
- `/profile` - Просмотр и обновление информации вашего профиля
- `/goal <калории>` - Установка ежедневой цели по калориям (например, `/goal 2000`)
- `/add` - Добавление блюда (отправьте фото или текстовое описание)
- `/today` - Просмотр сегодняшнего потребления калорий
- `/history <дни>` - Просмотр истории приемов пищи (по умолчанию: 7 дней)
- `/reminder <ЧЧ:ММ>` - Установка ежедневного времени напоминания (например, `/reminder 09:00`)

## Интеграция с API

Бот использует два основных API для распознавания еды и получения данных о питательных веществах:

1. **OpenRouter API**: Обрабатывает изображения еды и текстовые описания с использованием LLM для идентификации продуктов и оценки их питательной ценности
2. **USDA FoodData Central API**: Предоставляет точную информацию о питательных веществах для известных продуктов питания
