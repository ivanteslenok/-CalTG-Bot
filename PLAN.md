# План реализации CalTG

## Обзор проекта
CalTG - это Telegram бот для подсчета калорий, который использует ИИ для распознавания еды и API USDA для получения данных о питательной ценности.

## Реализованные ключевые функции

1. **Распознавание еды**:
   - Анализ изображений с использованием API OpenRouter
   - Анализ текстового описания еды
   - Данные о питательной ценности из API USDA

2. **Управление пользователями**:
   - Создание и обновление профиля
   - Персональные цели по калориям
   - Ежедневный подсчет калорий

3. **Регистрация приемов пищи**:
   - Регистрация еды по фотографии
   - Регистрация еды по текстовому описанию
   - Подробная информация о питательной ценности

4. **Отслеживание и история**:
   - Отслеживание ежедневного потребления калорий
   - Просмотр исторических данных о приемах пищи
   - Мониторинг прогресса

5. **Уведомления**:
   - Настраиваемые времена напоминаний
   - Автоматические напоминания о регистрации приемов пищи
